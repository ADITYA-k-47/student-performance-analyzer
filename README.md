# Student Performance Analyzer

## Overview
Student Performance Analyzer is a simple project in Python made to analyze the academic performance of the students.
This program accepts the student's name and the marks obtained in different subjects as input. It then calculates total marks obtained, average marks obtained, marks obtained in maximum subject, marks obtained in minimum subject. It also check whether he/she passes or not with given passing criteria.

The project is primarily built to practice the basic Python programming concepts learnt so that can be used in a realistic scenario.

## Features
- Enter student name
- Enter marks for different subjects
- Calculate total marks
- Calculate average marks
- Find highest marks
- Find lowest marks
- Check Pass/Fail result
- Display the final performance details
- Basic input validation

- Python 3.x

- Visual Studio Code or any other editor of your choice

## How to Run

1. Download or clone the repository

Open the terminal and clone the project:

git clone <your-github-repository-link>

2. Open the project folder

cd Student-Performance-Analyzer

3. Run the program
python studentperformanceanalyzer.py
If your system uses "python3", use:
python3 studentperformanceanalyzer.py

## How to Use
1. Run the Python program.
2. Enter the student's name.
3. Enter the marks when asked.
4. The program processes the entered marks.
5. The overall output appears on the screen.

Output will show the inputted student performance i.e. total, average, highest, lowest marks and a Pass/Fail result.

Testing

The program was tested by inputting various set of marks to see if it was calculating and producing the result correctly.

The following cases can be tested:
- Normal marks
- High marks
- Low marks
- Passing marks
- Failing marks
- Invalid input

The total, average, highest and lowest should agree with what was entered.
